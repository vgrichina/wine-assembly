Threads probe

Answers one question: can this browser run wine-assembly's guest threads as real Web Workers? That needs cross-origin isolation, a shared WebAssembly.Memory that survives postMessage, and a compiled module that links in a worker — including a module produced at load time by our own WAT → WASM compiler, which is how this project normally builds in the browser.

The code

where each part of the machine lives

emit.js

The generator: every handler once, emitted behind whichever dispatch shell is asked for.

decode.js

x86 bytes into arena words, with the fusion and spin-loop passes.

dos.js

The machine: DOS, BIOS, XMS, EMS, the VGA, the keyboard, the menu reader.

trace-jit.js

The tiers: stitching, constant propagation, register-file folding, dead flags.

region-jit.js

Installing a compiled region into the running program, and the gate that prices it.

live.js

The page-side driver behind every Run button here.

shot-sweep.js

The headless sweep that photographs the corpus and writes the JSON this site is built from.
